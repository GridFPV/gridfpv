# GridFPV

Free, open-source, all-in-one race management for FPV drone racing — real-world and
Velocidrone virtual racing as equals, in one self-hostable app.

## Documentation

Internal design and developer documentation lives in [`docs/`](docs/index.html) as HTML —
open [`docs/index.html`](docs/index.html) in a browser. Start with the
[**Vision**](docs/vision.html) for what GridFPV is and why it exists.

These docs are internal (design rationale and engineering record) and are not hosted.
User-facing documentation will live in a separate repository.
