# Data

Grid keeps everything in one folder on the computer it runs on. The Data page moves it all
to another computer.

The Data page is under **Setup**.

## What is in a copy

- pilots
- classes
- formats and seat profiles
- timers
- every event, with all its races and laps

These are not in a copy:

- the video setup. Each computer has its own OBS address and password.
- the recordings. They are big. They are in the `videos` folder inside Grid's data folder
  (or in OBS's folder, if you chose that). Copy them yourself.

## Saving a copy

Press **Save a copy**. Grid writes one zip file and shows where it is. It goes in the
`exports` folder inside Grid's data folder.

If you opened Grid from another computer, press **Download it here** to get the file on
that computer.

You can save a copy at any time, even during a race. Grid keeps the five newest copies it
has made.

## Bringing a copy in

1. Put the file on the other computer. A USB stick works.
2. Open Grid there and go to the Data page.
3. Press **Choose a file** and pick the copy.
4. Grid asks if you are sure. Press **Bring it in**.
5. Close Grid and open it again.

A copy **replaces** what that computer had. It does not mix the two together.

Nothing is deleted. What was there before is moved to the `backups` folder inside the data
folder.

Until you restart, nothing has changed. If you change your mind, press **Do not bring it
in**.

Grid will not take a copy while a race is on.

## Getting the old data back

Close Grid. Open the data folder, then `backups`. Each folder there is named after the day
and time a copy came in. Move its files back into the data folder and open Grid.

## Where the data is

The bottom of the Data page shows the folder. In the desktop app it is the `gridfpv-data`
folder next to the program.
