# Overlays

An overlay is a page you put on top of your video in OBS.

## Adding one to OBS

1. In OBS, add a **Browser** source.
2. Set its size to 1920 by 1080.
3. Copy the overlay's URL from this page and paste it in.

The overlay follows the event that is open in Grid. It only reads. Nothing you do in OBS
can change a race.

## The race overlay

It shows the race clock, the heat's name, and a line for each pilot with laps, last lap
and best lap. With one pilot it shows more: each recent lap, and the best run when the heat
is ranked on laps in a row. Between races it shows the last result for a short while.

## Contrast

Pick **Light text** for dark video and **Dark text** for bright video. The choice is part
of the URL, so copy the URL again after you change it.

## Preview

**Show preview** shows the overlay in a small frame on a plain backdrop. It is a second live
page, so it is opened only when you ask.

## Copy does not work

Some browsers only allow copying on a secure page. If **Copy URL** fails, select the URL and
copy it by hand.
