# Start here

Grid runs a race day from one screen in a browser. The pages along the top are in the
order you use them. Every page has a **?** next to its title that opens its help. This help
is built into Grid, so it works at a field with no internet.

## A race day, in order

1. **Event**: name the day and set the lap rules. See [Event](#/help/event).
2. **Seats**: pick each seat's channel and tune it so one pass makes one crossing. See
   [Seats](#/help/seats).
3. **Pilots**: add who is flying. Pilots are kept for next time. See [Pilots](#/help/pilots).
4. **Formats**: how one race is run and how a heat is ranked. Grid comes with four. See
   [Formats](#/help/formats).
5. **Phases**: add what will be raced: practice, qualifying, a bracket, or just one heat.
   See [Phases](#/help/phases).
6. **Run**: put a heat on the timer, start, stop, and save. See [Run](#/help/run).
7. **Marshal**: fix a lap after the race. See [Marshal](#/help/marshal).
8. **Results**: the standings. See [Results](#/help/results).

**Overlays** gives you pages to put on top of video in OBS. See [Overlays](#/help/overlays).

## Flying alone

To time yourself on a home track you need very little:

1. On the Events page (the event's name, top right), add an event.
2. On **Seats**, check that your timer is connected and Seat 1 is on your channel.
3. On **Pilots**, add yourself.
4. On **Phases**, press **Add heat**. Name it after the track, pick yourself, and pick the
   format **Best 3 consecutive**.
5. On **Run**, press **Start**, fly, press **Stop**, then **Save**. Start again as often as
   you like. The heat keeps your best run.

## What is kept where

- **Pilots, classes, formats, timers and seat profiles** belong to Grid. They are there for
  every event.
- **Phases, heats, races, laps and results** belong to one event.
- **Channels and levels** live on the timer. Grid reads them from the timer and writes them
  back. A seat profile is Grid's saved copy.
