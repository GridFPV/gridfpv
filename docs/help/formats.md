# Formats

A format is the set of rules for a heat. It answers three questions:

- How does **one race** end?
- When is **the heat** done?
- How is the heat **ranked**?

Formats belong to Grid and carry over between events. Grid starts with four: Practice,
Best 3 consecutive, First to 3 laps, and 2 minutes most laps. You can change or delete any
of them.

**New format** and **Duplicate** open a form. Nothing is saved until **Save format**. The
line at the bottom of the form says the format in plain words as you build it.

## One race

- **The race ends**: when you stop it, when a pilot finishes a set number of laps, or
  after a set time.
- **Laps to win**: for a race to a lap count.
- **Stop by itself after everyone finishes**: for a race to a lap count. Leave it empty and
  you stop the race yourself. A wait gives you time to sort out laps on a hard track.
- **Race time** and **Then to finish the lap**: for a timed race. When the time is up,
  pilots get this long to finish the lap they are on.
- **Time limit**: for a race that is not timed. The race stops here, whoever has finished.
- **Countdown before the start tone**: 0 starts the race at once.
- **Time lap 1 from the start tone**: left off, a pilot's first pass starts lap 1. That
  first pass is called the hole shot. Turned on, lap 1 starts at the tone.

## The heat

- **The heat is done**: when you call it done, after a set number of races, or when a
  pilot has a set number of wins.
- **Ranked by**:
  - **Not ranked** is for practice.
  - **Finishing order** ranks by who finished first in the race.
  - **Most laps** is for a timed race.
  - **Fastest single lap** ranks by each pilot's best lap.
  - **Fastest laps in a row** ranks by the best run of that many laps, back to back.
  - **Most wins** is for a heat raced until one pilot wins twice.
  - **Most points** adds up points over the heat's races. List the points for each place,
    first place first.

Every ranking ends the same way. Pilots who never flew go below those who did, and the
last tie-break is the order the pilots came into the heat.

## More

**Minimum lap time for this format** is almost always left empty. Then the format uses the
event's minimum lap time, set on the [Event](#/help/event) page.

## Changing a format later

A phase gets a copy of the format when it is given one. Editing the saved format does not
change that phase. To change the rules of a phase that has not raced yet, remove it on the
[Phases](#/help/phases) page and add it again.
