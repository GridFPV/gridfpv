# Details

An event is one race day. Its Details page shows what the open event is, the lap rules its
races run under, and the classes racing in it. It is the first page on the Event side.

## Opening and adding events

The open event's name is at the top right of every page. Click it, or switch to **Setup**
and open the **Events** page, to change events. There you can open another event, add a
new one, or delete one. Deleting an event
removes all of its races for good, so Grid asks you to type its name first.

## Details

**Edit** changes the event's name, date, location, organizer and description. These are
labels for people. They change nothing about how races are timed.

## Lap rules

Lap rules are set once for the whole event. They apply to every race in it, including
races already flown. Each one saves when you leave its field.

- **Minimum lap time**: a pass that comes sooner than this after the pilot's last one is
  not counted as a lap. The pass is kept. The [Marshal](#/help/marshal) page lists it
  under "Crossings that do not count", and **Count it** counts it if the lap was real.
  Leave it empty for no minimum.
- **Ignore crossings before**: passes in the first seconds after the start are not counted.
  This is for a take-off right under the gate. Passes before the start never count.

A good minimum lap time is a little shorter than the fastest lap anyone could fly on the
track.

The timer has a setting of its own called the **lap cooldown**. It is on the
[Seats](#/help/seats) page. Keep the cooldown shorter than the minimum lap time. If the
cooldown is longer, the timer hides passes before Grid ever sees them.

## Classes

A class is a name plus the pilots racing in it at this event.

- **Add class** picks a class from the class list and its pilots from the pilot list.
- **Edit roster** changes who is in it.
- **What counts** picks which phases decide the class's standings, in order. The first
  phase decides. A later one is only used for pilots the first one did not place.

You do not need a class to race. A heat can name its pilots directly. Add a class when you
want standings from first to last.
